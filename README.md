# Orunis: downloads do cliente

Instaladores do cliente do [Orunis](https://orunis.com.br). Baixe a versão mais recente em [Releases](https://github.com/ferjuncaz/orunis-releases/releases/latest).

Este repositório não tem código-fonte nem arquivos da CipSoft: os gráficos e sons do jogo são baixados pelo próprio cliente no primeiro login.

Projeto de fãs, sem vínculo com a CipSoft GmbH. Tibia é marca registrada da CipSoft GmbH.
